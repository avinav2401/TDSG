# 🚀 Trigger Tracker

**Trigger Tracker** is a 2D space shooter game built in **Java** using **Swing** for GUI and **SQLite** for data storage.  
Players can log in, play as a guest, earn coins, unlock spaceship skins, and compete on a global leaderboard.

---

## 🎮 Game Overview

Trigger Tracker is a fast-paced shooting game where players control a spaceship and survive waves of enemies while earning points and currency.  
The game combines **smooth gameplay mechanics**, a **dark-themed UI**, and **database-driven persistence** for player stats, skins, and leaderboard.

---

## 🧩 Features

### 👤 **User System**
- Login and Registration with SQLite authentication  
- Play as **Guest** (without login)  
- Persistent user data (scores, coins, skins) stored locally  

### 🕹️ **Gameplay**
- Classic space shooter mechanics  
- Player spaceship with multiple skins  
- Enemies spawn dynamically  
- Smooth animations and responsive controls  
- Pause, resume, and quit options  

### 🏆 **Leaderboard**
- Displays top players with their **high scores** and **currency**  
- Automatically updates after each game session  

### 🛒 **Shop / Skin Vault**
- Unlock new spaceship skins using in-game coins  
- Skins remain saved across sessions via SQLite database  

### 💾 **Database Integration**
- SQLite database (`game.db`) stores:
  - Player accounts (username, password)
  - Scores and currency
  - Unlocked skins and shop data  

---

## 🛠️ Technologies Used

| Component | Technology |
|------------|-------------|
| **Language** | Java (JDK 8+) |
| **GUI Framework** | Swing |
| **Database** | SQLite |
| **Game Loop / Logic** | Custom Java Threads |
| **Assets** | PNG Sprites for ships and enemies |
